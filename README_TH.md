# TGAT1 English Studio — Stability & Offline v13

## ไฟล์ในชุด
- `index.html` — แอปเต็มในไฟล์เดียว พร้อมคลังคำศัพท์และข้อสอบที่ฝังอยู่ในไฟล์
- `sw.js` — Service Worker สำหรับแคชตัวแอปและเปิดใช้งานออฟไลน์
- `manifest.webmanifest` และไอคอน — สำหรับติดตั้งเป็นเว็บแอป

## วิธีเปิดบน Chrome

**แนะนำเพื่อให้บันทึกข้อมูลและออฟไลน์ได้ครบ:** แตก ZIP แล้วนำทั้งโฟลเดอร์ขึ้นเว็บที่ใช้ HTTPS (เช่น static hosting) หรือเปิดผ่าน `localhost` บนเครื่องเดียวกัน

บนคอมพิวเตอร์ที่ติดตั้ง Python:

```bash
cd TGAT1_Studio_PWA_v13
python -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080` ด้วย Chrome ขณะออนไลน์ครั้งแรก เพื่อให้ Service Worker แคชไฟล์ทั้งหมด เมื่อเปิดแอปแล้วจึงตัดอินเทอร์เน็ตและทดสอบเปิดซ้ำได้ จากเมนู Chrome เลือก Install app / ติดตั้งแอป ได้เมื่อ Chrome แสดงตัวเลือก

**มือถือ/แท็บเล็ต:** เปิด URL แบบ HTTPS ที่โฮสต์โฟลเดอร์นี้ (หรือ localhost บนอุปกรณ์เดียวกัน) แล้วเพิ่มไปยังหน้าจอหลัก/ติดตั้งเว็บแอป การเปิดไฟล์ `index.html` จาก Downloads โดยตรงไม่ใช่วิธีที่แนะนำสำหรับการบันทึกถาวรและ Service Worker

## การสำรองข้อมูล
- แอปยังคงบันทึกสถานะการเรียน/รอบสอบใน localStorage เพื่อให้เข้ากับระบบเดิม
- ใน Chrome ที่อนุญาต IndexedDB จะมีสำเนากู้คืนอัตโนมัติภายใน origin เดียวกัน
- ไปที่ ตั้งค่าและสำรองข้อมูล → ศูนย์ตรวจสุขภาพแอป เพื่อตรวจสถานะและดาวน์โหลด JSON backup
- เก็บ JSON backup ไว้ในอุปกรณ์/Cloud Drive แยกต่างหาก และส่งออกก่อนล้างข้อมูลเว็บไซต์หรือย้ายเครื่อง
- checksum ตรวจจับความเสียหายที่เกิดโดยไม่ตั้งใจ ไม่ใช่ลายเซ็นรับรองผู้ส่งหรือระบบเข้ารหัส

## ข้อจำกัดที่ควรรู้
- Service Worker ต้องทำงานบน HTTPS หรือ localhost; ไม่ทำงานเมื่อเปิดผ่าน `file://`
- IndexedDB/localStorage อยู่ภายใต้พื้นที่จัดเก็บของ browser origin เดิม และอาจถูกลบได้เมื่อผู้ใช้ล้างข้อมูลเว็บไซต์หรือระบบปฏิบัติการจัดการพื้นที่
- แอปเป็นแบบ offline-first หลังจากโหลด/แคชสำเร็จครั้งแรก ไม่สามารถทำงานออฟไลน์ก่อนการโหลดครั้งแรกได้
- ไฟล์นี้ไม่มี backend/cloud sync; การย้ายอุปกรณ์ต้องใช้ไฟล์ JSON backup
